Как работать

  1. Тур на неделю. «Неделя» → «Ближайшие заезды» → нажмите на тур. В конструкторе отметьте форматы (у каждого — свой день) и площадки → «Сделать всё». Бестик напишет весь пакет одним заходом.
  2. Каждый день. «Неделя» → карточки на сегодня. Текст готов — «Открыть текст»: внутри пакета вкладки по форматам.
  3. Видео. «Рилс · CapCut» — текст на экран для каждого кусочка с секундами, подпись и хештеги: монтируете в CapCut по своим шаблонам. «Разговорное видео» — сценарий для гида: реплики, доп. кадры и памятка по съёмке; внизу «Всё одним сообщением» — «Копировать» и переслать гиду.
  4. Выкладываем. В тексте нажимайте «Копировать» у каждого слоя и вставляйте: в Crsel, CapCut, Recur, ВК/ОК/Telegram/Threads, Авито. Выложили — «Опубликовано».
  5. Чужое фото с отметкой. «Тексты» → шаблон «Запрос согласия автора» → «Копировать» → отправьте автору. Без «да» не публикуем.
  6. Своё. Написали сами — «Тексты» → «Проверить свой текст».
  7. Мак выключен. Заказ текста ляжет в «Задачи для Мака», карточка покажет «Ждёт Мака». Включится — Бестик пришлёт список в чат.

Правила бренда

Цена — как известна: есть цена из Краснодара — «до X ₽»; одна цена для всех городов — «X ₽»; известна только минимальная — «от X ₽». Бестик берёт её из каталога сам.

Не писать в текстах для публикации: «Инстаграм», «Instagram», «соцсети», «социальные сети» — вместо них «в наших публикациях», «у нас».

Только факты из каталога и сайта: цены, даты, отзывы, места. Нет данных — «[уточнить]».

Тон — тёплый, живой, от «мы», к клиентам на «вы». Без пафоса и превосходных степеней («самый», «лучший»), если их нет в отзывах.

Чужие фото и видео с отметками — только с согласия автора (скриншот переписки — в папку «Согласования»).

Авито: одно объявление — один тур; тот же тур повторно не раньше чем через 30 дней; без телефонов и ссылок в тексте; без КАПСа.

«нет на сайте» — тур не предлагаем.
